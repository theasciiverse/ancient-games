# About this book

These are the rules of the games in Asciiverse's Ancient Games collection,
with where each rule comes from.

None of these games comes down to us with its rules intact. What we have
are boards, pieces and dice from tombs and excavations, a few texts, and
the reconstructions scholars and game makers have built on them. Where
more than one honest reconstruction exists, the games offer each of them,
and this book sets them side by side.

Every chapter keeps three kinds of statement apart:

- **What survives**: boards, pieces, texts, with the source that
  describes them.
- **What is reconstructed**: a scholar's or game maker's proposal, named
  as theirs.
- **Our choice**: where every source is silent and the program still has
  to do something. These are marked "Our choice" wherever they appear, so
  they can never be mistaken for history.

A source we have not read ourselves, only seen cited in another, is
cited "as cited in" that other source.

The rules here are the rules the programs play. When a program and this
book disagree, that is a bug in one of them; please report it.
